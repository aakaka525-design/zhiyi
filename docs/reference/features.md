# 功能说明

> 当前版本已移除图片 OCR、漫画翻译与 Native Host，本页仅描述仍然保留的功能。

## 1. 划词翻译

**触发方式**: 选中网页文本后，通过气泡、侧边栏或悬浮窗查看翻译结果。

**展示方式**:
- 气泡翻译
- 侧边栏翻译
- 悬浮翻译窗口

**相关模块**: 见 [架构设计](./architecture.md) 中的内容脚本与消息流说明。

---

## 2. 沉浸式翻译

**触发方式**: 快捷键 `Alt+I` 或右键菜单。

**工作原理**: 遍历页面文本节点，在原文下方插入译文，形成双语对照阅读体验。

**特性**:
- 保留原页面布局
- 仅处理新增或待翻译节点
- 支持动态内容刷新

**相关模块**: 见 [架构设计](./architecture.md) 中的内容脚本与消息流说明。

---

## 3. PDF 模块（未开放入口）

**触发方式**: 当前版本未在 Popup 中开放 PDF 入口。

**说明**: 仓库仍保留基础处理模块 `src/core/pdf.js`，但产品入口暂未开放。

**相关模块**: 见 [架构设计](./architecture.md) 中的 Popup、Service Worker 与 `src/core` 分层说明。

---

## 4. 语音朗读 (TTS)

**支持配置项**:
- 系统语音
- OpenAI TTS
- Google Cloud TTS
- GLM TTS

**播放方式**: 通过 Offscreen Document 在后台播放音频。

**相关模块**: 见 [架构设计](./architecture.md) 中的 TTS Action、Service Worker 与 Offscreen Document 说明。

---

## 5. 广告拦截

**实现方式**: 内容脚本在页面内执行 DOM 级广告清理。

**相关模块**: 见 [架构设计](./architecture.md) 中的内容脚本加载顺序说明。

---

## 6. 翻译弹窗 (Popup)

**功能**:
- 文本输入翻译
- 语言选择
- 基于当前 TTS 配置的朗读
- 历史记录入口
- 收藏管理
- 功能快捷入口

**相关模块**: 见 [架构设计](./architecture.md) 中的 Popup UI 与消息流说明。

---

## 7. 设置管理 (Options)

**可配置项**:
- 默认翻译引擎与 API 密钥
- 划词翻译、快捷键、悬浮球、广告拦截等开关
- 深色模式与调试模式
- TTS 服务与语速
- 历史与收藏管理

**相关模块**: 见 [架构设计](./architecture.md) 中的 Options Page、数据存储与消息流说明。
